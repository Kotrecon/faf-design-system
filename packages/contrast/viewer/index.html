💻 Code Example

import { FafContrast } from '@faf/contrast';

const isAccessible = FafContrast.isAccessible(
  '#111827',      // foreground
  '#ffffff',      // background
  'AA',           // WCAG level
  'normal'        // text size
);

console.log(isAccessible); // true

WCAG Contrast Guide

What is WCAG?

WCAG (Web Content Accessibility Guidelines) is the international standard for web accessibility. It defines requirements to make web content more accessible to people with disabilities.

Contrast Requirements

Level Normal Text Large Text
WCAG AA ≥ 4.5:1 ≥ 3.0:1
WCAG AAA ≥ 7.0:1 ≥ 4.5:1

What is Large Text?

Large text is defined as:

  • Font size ≥ 18pt (24px), OR
  • Font size ≥ 14pt (18.5px) with bold weight

How Contrast is Calculated

Contrast ratio is calculated using the Relative Luminance formula:

  1. Convert color to linear sRGB (gamma correction)
  2. Calculate luminance: L = 0.2126 × R + 0.7152 × G + 0.0722 × B
  3. Calculate contrast: CR = (L_lighter + 0.05) / (L_darker + 0.05)

⚠️ Limitations

  • This implementation uses a simplified oklch→RGB conversion (error ~2-5%).
  • For production, use culori or colorjs.io libraries.
  • Supports WCAG 2.1 only (without 2.2 criteria).
  • Does not implement APCA (Advanced Perceptual Contrast Algorithm).
