💻 Code Example / Пример кода

import { FafContrast } from '@faf/contrast';

const isAccessible = FafContrast.isAccessible(
  '#111827',      // foreground
  '#ffffff',      // background
  'AA',           // WCAG level
  'normal'        // text size
);

console.log(isAccessible); // true

WCAG Contrast Guide / Руководство по контрастности WCAG

What is WCAG? / Что такое WCAG?

WCAG (Web Content Accessibility Guidelines) is the international standard for web accessibility. It defines requirements to make web content more accessible to people with disabilities.
WCAG (Руководство по доступности веб-контента) — международный стандарт веб-доступности. Он определяет требования для того, чтобы веб-контент был более доступным для людей с ограниченными возможностями.

Contrast Requirements / Требования к контрастности

Level / Уровень Normal Text / Обычный текст Large Text / Крупный текст
WCAG AA ≥ 4.5:1 ≥ 3.0:1
WCAG AAA ≥ 7.0:1 ≥ 4.5:1

What is Large Text? / Что такое крупный текст?

Large text is defined as: / Крупный текст определяется как:

  • Font size ≥ 18pt (24px), OR / Размер шрифта ≥ 18pt (24px), ИЛИ
  • Font size ≥ 14pt (18.5px) with bold weight / Размер шрифта ≥ 14pt (18.5px) с жирным начертанием

How Contrast is Calculated / Как рассчитывается контрастность

Contrast ratio is calculated using the Relative Luminance formula:
Коэффициент контрастности рассчитывается по формуле Относительной яркости (Relative Luminance):

  1. Convert color to linear sRGB (gamma correction) / Конвертация цвета в линейный sRGB (гамма-коррекция)
  2. Calculate luminance: L = 0.2126 × R + 0.7152 × G + 0.0722 × B / Расчёт яркости: L = 0.2126 × R + 0.7152 × G + 0.0722 × B
  3. Calculate contrast: CR = (L_lighter + 0.05) / (L_darker + 0.05) / Расчёт контраста: CR = (L_светлее + 0.05) / (L_темнее + 0.05)

⚠️ Limitations / Ограничения

  • This implementation uses a simplified oklch→RGB conversion (error ~2-5%). / Данная реализация использует упрощённую конвертацию oklch→RGB (погрешность ~2-5%).
  • For production, use culori or colorjs.io libraries. / Для production используйте библиотеки culori или colorjs.io.
  • Supports WCAG 2.1 only (without 2.2 criteria). / Поддерживает только WCAG 2.1 (без критериев 2.2).
  • Does not implement APCA (Advanced Perceptual Contrast Algorithm). / Не реализует APCA (Advanced Perceptual Contrast Algorithm).
