# Руководство по контрастности WCAG

## Что такое WCAG?

**WCAG (Web Content Accessibility Guidelines)** — это международный стандарт доступности веб-контента, разработанный консорциумом W3C. Он предоставляет единые требования к доступности, удовлетворяющие потребности пользователей, организаций и государств.

## Требования к контрастности (WCAG 2.1)

Контрастность измеряется как отношение относительной яркости переднего плана (текст/иконка) к фону. Коэффициент варьируется от 1:1 (отсутствие контраста) до 21:1 (максимальный контраст, чёрный на белом).

| Уровень                            | Обычный текст | Крупный текст (Large Text) |
| :--------------------------------- | :------------ | :------------------------- |
| **WCAG AA** (Минимальный стандарт) | ≥ 4.5:1       | ≥ 3.0:1                    |
| **WCAG AAA** (Улучшенный стандарт) | ≥ 7.0:1       | ≥ 4.5:1                    |

## Что такое "Крупный текст" (Large Text)?

WCAG определяет крупный текст как:

- Размер шрифта **≥ 18pt (24px)**, ИЛИ
- Размер шрифта **≥ 14pt (18.5px)** с начертанием **bold** (жирный).

К крупному тексту применяются сниженные требования к контрастности, поскольку увеличенный размер и жирность делают его легче читаемым даже при меньшем контрасте.

## Как рассчитывается контрастность

1. **Линеаризация**: Преобразование каналов sRGB (0-255) в линейные значения для учёта гамма-коррекции монитора.
   - Если $C_{srgb} \le 0.03928$, то $C_{lin} = C_{srgb} / 12.92$
   - Если $C_{srgb} > 0.03928$, то $C_{lin} = ((C_{srgb} + 0.055) / 1.055)^{2.4}$
2. **Относительная яркость ($L$)**: Расчёт воспринимаемой яркости.
   - $L = 0.2126 \times R_{lin} + 0.7152 \times G_{lin} + 0.0722 \times B_{lin}$
3. **Коэффициент контрастности ($CR$)**:
   - $CR = (L_{светлее} + 0.05) / (L_{темнее} + 0.05)$

> 💡 **Примечание**: Утилита `@faf/contrast` реализует эти формулы в точном соответствии со спецификацией. Для цветов в формате `oklch` используется упрощённая конвертация. См. раздел [Ограничения и допуски](../README.ru.md#ограничения-и-допуски) для рекомендаций по production-среде.
