# Руководство по лучшим практикам контрастности

## Общие рекомендации

1. **Текст на светлом фоне**: Используйте оттенки **700–900** для гарантированного прохождения WCAG AA.
2. **Текст на тёмном фоне**: Используйте оттенки **100–300**.
3. **Кольцо фокуса (Focus Ring)**: Должно быть чётко видно на _любом_ фоне. Рекомендуется минимальное соотношение 3:1, но 4.5:1 является более надёжным выбором.
4. **Иконки и контуры**: Относитесь к ним как к обычному тексту. Требуется минимум 3:1 для крупных иконок и 4.5:1 для стандартных.

## Ловушка "Warning Color" (Жёлтый цвет)

Жёлтые/янтарные цвета (например, `--faf-color-warning`) очень часто не проходят проверку WCAG AA при размещении на белом фоне.
**Решения**:

- Используйте более тёмный оттенок жёлтого/оранжевого для текста или иконки.
- Добавьте тёмную обводку или тень к жёлтому элементу.
- Используйте жёлтый цвет только в качестве фона с тёмным текстом внутри него.

## Парсинг цветов в Production

Текущая реализация парсинга `oklch` в `@faf/contrast` использует упрощённую математическую аппроксимацию в учебных целях.

**Для Production**: Замените внутренний метод `parseOklch` на проверенную библиотеку, такую как [`culori`](https://culorijs.org) или [`colorjs.io`](https://colorjs.io). Это обеспечит 100% точность конвертации цветовых пространств (oklch → oklab → XYZ D65 → linear sRGB → sRGB).

Пример с `culori`:

```typescript
import { convertColor } from "culori";

// Замените упрощённую логику на:
const rgb = convertColor("oklch(0.55 0.22 250)", "rgb");
const r = rgb.r * 255;
const g = rgb.g * 255;
const b = rgb.b * 255;
```
