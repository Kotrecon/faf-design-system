.faf-paragraph (base)

Это базовый параграф с fluid-типографикой. Размер шрифта плавно меняется от 1rem до 1.125rem в зависимости от ширины viewport. Текст легко читается на любом устройстве — от мобильного телефона до большого монитора. Fluid typography заменяет необходимость писать медиа-запросы для каждого размера шрифта отдельно.

This is a base paragraph with fluid typography. The font size changes smoothly from 1rem to 1.125rem depending on the viewport width. The text is easy to read on any device — from a mobile phone to a large monitor. Fluid typography eliminates the need to write media queries for each font size separately.
